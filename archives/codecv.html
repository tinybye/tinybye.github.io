安仔

又到了金九银十的招聘季，不过这几年求职环境越来越差，相比于跳槽找新机会，大家可能更倾向于守住自己手头的工作，稳字当头。当然，也有很多工作实在干烦了的朋友，想要换个新赛道试试。每年的这个时候，都会给大家分享一些生成简历的项目。今天就给大家带来一个新的开源简历工具项目——codecv。

项目简介

codecv 是一款制作简历的工具，它自带了适合各行各业的海量的简历模板供你选择，你可以在此基础上使用 markdown 语法修改和编写你的简历。同时，它也可以将你编写的 markdown 简历转为 PDF。

项目使用

项目提供了 docker 部署方式，本地部署非常方便，用这个命令就可以了：

部署完成后，打开你的浏览器访问服务的地址 localhost:8080 就可以进入 codecv 的首页了。

点击“快速开始”按钮，可以看到有适合各种行业的模板。

我们选择一个模板，点击“使用模板”按钮，就可以跳转到简历的编辑页面，如图：

在左侧我们编辑简历，右侧可以实时的预览简历。编辑区域的功能非常丰富，我们可以插入证件照格式、图标、个人信息布局、表格等等，让我们的简历变得更加丰富。在右侧的预览区域也可以修改行高、颜色、字体等。

简历编辑完成后，点击右上角导出就可以将简历导出成 pdf 格式，如果导出失败，也可以进行备用导出。

总结

codecv 是个上手简单的简历制作工具，你可以自己使用它来制作简历，也可以搭建成一个在线网站，让朋友们一起使用。在金九银十的就业季，做好一个简历对自己的求职还是很有帮助的，感兴趣的朋友们可以去试试哈。
