安仔

不知道大家有没有这样的需求，拍摄了好几百张照片，想要给照片按照新的规则命名。或者是下载了很多数据文件，想要统一的替换一下文件的名称。对于一些技术高超的程序员来说，可能随手写个批处理或者是 shell 脚本就能实现了。

但是并不是所有人都会写脚本呀，所以今天就给大家推荐一个简单好用的开源项目——FreeReNamer。

项目简介

正如其名字所说，FreeReNamer 是一款免费且功能强大又易用的文件批量重命名软件。使用它可以快速的对多个文件进行批量命名处理，且支持配置多个灵活的命名规则。

FreeReNamer 提供了 Windows 平台和 macOS 平台的客户端，也支持访问 web 端去实现命名功能。不过网页端使用的 FileSystemHandle 的 move api，兼容性较差，推荐使用最新版本的 chrome 浏览器。客户端是原生 API，兼容性没问题。

所以我们去项目的 release 主页下载自己系统的客户端安装包就可以了。

项目使用

点击“添加规则”按钮，我们可以看到，可以创建替换、删除、格式化、插入等多个类型的规则。

总结

FreeReNamer 是一款非常方便实用的文件批量重命名软件，对于摄影师来说，它可以帮助你给多张照片添加统一的前缀；对于数据处理人员来说，它可以帮助你给多个数据文件按照统一的格式命名。感兴趣的朋友赶快去试试吧。
